存储介质回顾

UFS / eMMC / SSD 的内部，真正存储数据的是 NAND 闪存芯片。 它不是抽象的"存储空间"，而是由数十亿个浮栅晶体管组成的物理阵列。

本集目标

从最小存储单元讲起，逐层拆解：
浮栅晶体管 → 页/块/平面/晶圆 → 为什么不能直接覆写 → GC 与写放大

LAYER 1 · FLOATING GATE TRANSISTOR03 / 12

最小存储单元：浮栅晶体管

工作原理

在普通 MOS 管的栅极中嵌入一个被绝缘层完全包裹的"浮栅"。电荷一旦注入就难以逃逸——断电后数据依然保存。

写入 Program

向浮栅注入电子 → 阈值电压升高 → 代表逻辑 "0"

擦除 Erase

从浮栅移除电子 → 阈值电压降低 → 代表逻辑 "1"

📌 浮栅被高质量氧化物绝缘层完全包裹，注入的电子几乎无法泄漏——这就是 NAND 非易失性存储的物理基础。

OPERATIONS · 读写擦05 / 12

为什么读/写按页，擦除按块？

读 / 写 → 按页

每次读写以 2KB / 4KB / 16KB 为单位
速度快（微秒级）
页是 NAND 内部最小的可寻址读写单元

⚡ 读 ~50μs / 写 ~500μs
擦除 → 按块

只能以 整个 Block 为单位
速度慢（毫秒级）
包含数百~数千个 Page

🐢 擦除 ~2-5ms（慢 10 倍）
KEY CONSTRAINT · 核心限制06 / 12

关键限制：不能直接覆盖写入

❌ 直观想法（但做不到）

找到旧数据的位置 → 原地写入新数据

问题：NAND 物理上做不到
必须先擦除整个 Block
✅ 实际流程

新数据 → 已擦除的空 Page → 旧 Page 标记"无效" → 后台 GC 回收

这就是"越用越慢"的物理根源
无效页越积越多，直到触发 GC
GARBAGE COLLECTION07 / 12

垃圾回收 GC：NAND 的"清洁工"

1
选择目标 · 选一个"脏"Block——含大量已标记无效的 Page
2
数据迁移 · 把 Block 中仍然有效的 Page 搬到一个新 Block
3
整块擦除 · 旧 Block 全部擦除，恢复为空闲空间
!
代价 · 消耗一次 P/E Cycle + 搬移有效数据产生额外写入 → 写放大
WRITE AMPLIFICATION08 / 12

写放大 WA = NAND 实际写入 ÷ 主机请求写入

WA 总是 > 1。GC 搬移有效数据产生额外写入——WA 越大，P/E Cycle 消耗越快，寿命越短。

⚡
顺序大文件
1.0-1.2×
接近理想值
⚠️
随机小文件
1.5-3.0×
GC 开销大
🔴
盘满时随机写
3.0-10+×
空间越少越糟

💡 减少写放大的关键：保留足够的空闲空间（Over-Provisioning）让 GC 有周转余地

THE BIG THREE · 三大机制10 / 12

NAND 闪存的三大核心机制

01

不能直接覆写

新数据→空Page→旧Page标记无效。物理限制是一切衍生机制的根源。

02

GC 垃圾回收

搬移有效页→擦除旧Block→回收空间。后台自动运行，消耗P/E Cycle。

03

写放大 WA

WA=NAND实际写入÷主机请求。越大越伤寿命，盘满时严重恶化。

TAKEAWAY11 / 12

NAND 是物理规律的妥协
不是完美的设计

高密度、低成本、非易失性 → 优势

不能直接覆写、擦除次数有限、需要 GC → 代价

理解这些底层机制，才真正理解了存储为什么"越用越慢"、为什么"参数不等于体验"。
